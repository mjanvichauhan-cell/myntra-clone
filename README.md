# 🛍️ Myntra Clone

A responsive front-end clone of the Myntra homepage built using **HTML5, CSS3, and JavaScript**. This project recreates the modern shopping experience of Myntra with interactive UI components, responsive layouts, and dynamic functionality using the DOM.

!myntra-clone[myntracloneimg.png]

## ✨ Features

- Responsive homepage layout
- Interactive navigation menu
- Mobile menu toggle using JavaScript
- Automatic bank offer carousel
- Clickable carousel navigation dots
- Shop by Category section
- Pocket Friendly Picks section
- Smooth UI animations and transitions
- Font Awesome icons
- Google Fonts integration
- Clean and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- Event Listeners
- CSS Variables
- Flexbox
- CSS Grid
- Font Awesome CDN
- Google Fonts (Poppins)

## 📚 JavaScript Concepts Used

- DOM Selection (`getElementById`, `querySelector`, `querySelectorAll`)
- Event Listeners (`addEventListener`)
- Class Manipulation (`classList.toggle`, `classList.add`, `classList.remove`)
- Dynamic HTML Updates (`innerHTML`)
- Accessibility Attributes (`aria-expanded`)
- Timers (`setInterval`)
- Functions and Conditional Statements
